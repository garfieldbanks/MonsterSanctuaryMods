## Convert README to BBCode

Run from the repo root:

```
cd /d "e:\Projects\games\monster.sanctuary\MonsterSanctuaryMods" && "D:\Apps\md2nexus\md2nexus.exe" -i README.md -o README.bbcode
```

Output is written to `README.bbcode` in the repo root. Remove the compilation section when updating the nexus page.
